# moizahmedd/tap

```sh
brew install moizahmedd/tap/betterairdrop
```

[BetterAirdrop](https://github.com/MoizAhmedd/betterairdrop): names your AirDropped photos by what's in them.

`Casks/betterairdrop.rb` is written by BetterAirdrop's release workflow on every tag. Don't edit it here;
edit `packaging/homebrew/betterairdrop.rb` in the app's repo.
